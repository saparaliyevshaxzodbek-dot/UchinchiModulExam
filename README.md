# C# Module 3 — Exam: Questions API

Exam project: a small layered ASP.NET Core Web API for managing questions.

## What's inside

- `QuestionsController` — REST endpoints
- `IQuestionService` / `QuestionService` — business logic
- `IQuestionRepositorie` / `QuestionRepositorie` — data access
- `QuestionCreateDto`, `QuestionGetDto`

## Tech

C# · ASP.NET Core Web API · Swagger

## Run

Requires the .NET SDK.

```bash
cd 3_Modul_Exam/src/ExamProject
dotnet run
```
